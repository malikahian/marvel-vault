## 📖 About
Marvel Character Vault is a React application that allows users to browse, filter, and manage their favourite Marvel characters. Inspired by a game collection app, but themed around the Marvel Cinematic Universe.

## ✨ Features
- 📋 Display Marvel characters in a card grid layout
- 🔍 Search characters by name or real name
- 🎯 Filter characters by category (Male, Female, Animal) or team
- ➕ Add new characters to the vault
- ⭐ Star rating system for each character
- 📊 Live character count display
- 🎨 Dark Marvel themed UI

## 🛠️ Built With
- [React](https://react.dev/) — UI library
- [Vite](https://vite.dev/) — Build tool
- [React Bootstrap](https://react-bootstrap.github.io/) — UI components
- [Bootstrap](https://getbootstrap.com/) — CSS framework
